## The experience

A player connects a Robinhood mainnet wallet holding a Generations NFT (gen 1+). Their selected Friend is rendered as a deep-sea captain at the helm. Casting bait triggers the SDK's chance game. The outcome table returns one of five NFT fish:

| Tier | Fish | Chance | Reward (RF) |
|---|---|---|---|
| Common | Coral Pebble NFT | 35% | 0.2 |
| Uncommon | Sunfish NFT | 28% | 0.6 |
| Rare | Rainbow Trout NFT | 18% | 1.5 |
| Epic | Koi NFT | 12% | 3.0 |
| Legendary | Dragon Carp NFT | 7% | 10 |

Fish are added to the player's collection with rarity tags. All outcomes are simulated in preview mode; no live contract calls are required to play.

## How to run

### Prerequisites

- Linux (or Ubuntu in WSL2 on Windows)
- Node.js 22+
- npm
- Git
- Robinhood mainnet wallet holding a Generations NFT (gen 1+) — for the wallet connection screen

### Setup

```sh
git clone https://github.com/your-username/rarefriends-vibeathon.git
cd rarefriends-vibeathon
npm ci
npm run build
node scripts/dev-game.mjs init games/deep-sea-treasures
cp submissions/deep-sea-treasures/* games/deep-sea-treasures/
npm run dev:game -- games/deep-sea-treasures
```

Open the displayed URL (normally `http://localhost:4173`), connect your wallet, choose your Friend, and start fishing.

### Controls

| Input | Action |
|---|---|
| WASD / Arrow keys / Tap | Move captain |
| Space | Cast bait |
| Tab | Open collection |
| Esc | Settings |
| M | Mute audio |

## Known issues

- Player must hold a real Generations NFT for the wallet selection screen, even in preview.
- Robinhood mainnet RPC may rate-limit under heavy load.
- Fish art is AI-generated and may benefit from manual refinement for production use.
- Live mode (real $RAREFRIENDS settlements) is not enabled in this MVP.
